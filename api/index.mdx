A API v1 da LibCloud permite acompanhar e controlar as hospedagens da sua conta a partir do servidor da sua integração. Todas as chamadas usam HTTPS e um token criado na dashboard.

## Comece pela autenticação

1. Abra **Configurações → API de integração** na dashboard.
2. Informe um nome para a integração e clique em **Criar token**.
3. Copie o token exibido e guarde-o em uma variável de ambiente no seu servidor. Ele só aparece uma vez.
4. Envie o cabeçalho `Authorization: Bearer` em cada chamada.

Você pode manter até cinco tokens ativos. Os tokens permitem consultar plano e consumo e solicitar parada ou reinício dos seus bots. Revogue um token na mesma tela para interromper seu acesso imediatamente. Uma conta suspensa ou com acesso revogado também perde acesso à API.

<Warning> O token funciona como uma senha da integração. Não coloque o segredo em URLs, código público ou JavaScript enviado ao navegador. </Warning>

## Primeira consulta

Use o token salvo no ambiente, sem escrevê-lo diretamente no comando:

```bash
curl --fail-with-body \
  -H "Authorization: Bearer $LIBCLOUD_TOKEN" \
  https://cloud.libgroup.site/api/v1/bots
```

Uma conta sem hospedagem retorna:

```json
{"bots": []}
```

Se houver hospedagem, a lista contém `id`, `name`, `status` e `action`. Use o `id` retornado nas chamadas de consumo e controle.

## Recursos disponíveis

A base é `https://cloud.libgroup.site/api/v1`.

| Método e rota | Resultado |
| --- | --- |
| `GET /me/plan` | Plano da conta, validade, limites e cotas API |
| `GET /bots` | Lista de bots da conta e estado de cada um |
| `GET /bots/{id}/usage` | Consumo de RAM, CPU e armazenamento com horários de medição |
| `POST /bots/{id}/stop` | Solicita parada do bot |
| `POST /bots/{id}/restart` | Solicita reinício do bot |

As operações POST não aceitam corpo. Uma resposta `202` confirma que a ação foi aceita, e não que o processo terminou. Consulte `GET /bots` para acompanhar o resultado. Se já existir uma operação pendente, a API pode responder `409`.

A [referência de endpoints](/api-reference/get-me-plan) detalha os parâmetros e formatos de resposta. Consulte também [limites e erros](/api/limits).

## Permissões

Cada token só acessa os bots da conta que o criou. Um identificador de outro cliente retorna `404`. O token não abre uma sessão na dashboard nem autoriza operações administrativas.

Shell interativo ainda não está disponível na API v1. O console atual da dashboard envia texto para a entrada padrão do processo, quando o bot está preparado para recebê-lo.
